# Security Policy

Fate's Edge is a hobby open-source project. There's no bug bounty, but security reports are taken seriously and handled promptly.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities. Instead, email **support@fates-edge.com** with:

- A description of the issue and its potential impact
- Steps to reproduce (a minimal example helps a lot)
- Any suggested fix, if you have one

You should get a response within a few days. Once a fix is available, credit is given in the release notes unless you'd prefer to stay anonymous.

## Scope

This applies to code in this repository. For issues in a dependency, please report upstream as well — a note here so we can track it is still appreciated.
