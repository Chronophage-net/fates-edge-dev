# Repo Map

| Repo | What's in it | File bugs/features here when... |
|---|---|---|
| [`fates-edge-ai-gm-bot`](https://github.com/Chronophage-net/fates-edge-ai-gm-bot) | Rules engine, AI GM, Tag DSL, transport layer | The issue is about game logic, the AI GM, LLM drivers, or real-time event delivery |
| [`fates-edge-apps`](https://github.com/Chronophage-net/fates-edge-apps) | Web client, terminal client, voice tools, utilities | The issue is about a client surface's UI, offline mode, dice UX, or voice pipeline |
| [`fates-edge-docs`](https://github.com/Chronophage-net/fates-edge-docs) | Rulebook, SRD, Art Bible, worldbook | The issue is a rules erratum, typo, or a content/setting proposal |
| [`fate-edge-dev`](https://github.com/Chronophage-net/fate-edge-dev) | This portal + wiki | The issue is about the portal site itself, or you're not sure where else it goes |
| [`fates-edge-blog`](https://github.com/Chronophage-net/fates-edge-blog) | Dev blog | The issue is about a blog post or the blog site itself |

Not sure? Open it in `fate-edge-dev` or ask in [Discussions](https://github.com/Chronophage-net/fate-edge-dev/discussions) — it's easy to move an issue once triaged.
