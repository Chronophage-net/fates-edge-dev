# Fate's Edge Developer Wiki

This wiki is for living, evolving reference material that changes too often (or is too collaborative) for the [dev portal](https://dev.fates-edge.com)'s versioned pages — think working notes, in-progress design discussions, and detailed how-tos, rather than the stable "what is this project" pages the portal already covers.

**Start here:**
- [Getting Started](Getting-Started) — environment setup across all four repos
- [Repo Map](Repo-Map) — what lives where, and which issue tracker a bug belongs in
- [Tag DSL Reference](Tag-DSL-Reference) — the living, contributor-editable directive list (the portal's [architecture page](https://dev.fates-edge.com/architecture#tag-dsl) covers the *why*; this page covers the current *what*)
- [FAQ](FAQ)

**Where things belong:**
| If you want to... | Go to |
|---|---|
| Understand the system design | [dev.fates-edge.com/architecture](https://dev.fates-edge.com/architecture) |
| Find a way to contribute | [dev.fates-edge.com/contribute](https://dev.fates-edge.com/contribute) |
| Ask a question or float an idea | [Discussions](https://github.com/Chronophage-net/fate-edge-dev/discussions) |
| Report a bug or request a feature | The relevant repo's Issues (see [Repo Map](Repo-Map)) |
| Look up or propose a working-notes doc | You're in the right place |

Wiki edits don't need a PR review — if you see something stale, fix it.
