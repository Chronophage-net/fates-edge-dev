# Getting Started

## Clone what you need

Most contributors only need one or two of these:

```bash
git clone git@github.com:Chronophage-net/fates-edge-ai-gm-bot.git   # rules engine, AI GM, Tag DSL, transport
git clone git@github.com:Chronophage-net/fates-edge-apps.git        # web client, terminal client, utilities
git clone git@github.com:Chronophage-net/fate-edge-dev.git          # this portal + wiki
```

## Which repo do I need?

See [Repo Map](Repo-Map) for the full breakdown, or the guided links on [Ways to Contribute](https://dev.fates-edge.com/contribute).

## First-time setup

1. Read the [architecture overview](https://dev.fates-edge.com/architecture) — five minutes, saves everyone time later.
2. Pick something from [Ways to Contribute](https://dev.fates-edge.com/contribute), or bring your own idea to [Discussions](https://github.com/Chronophage-net/fate-edge-dev/discussions) first.
3. Open an issue using the repo's issue template before a large PR.
4. Small, focused PRs are preferred over big ones.

## Local dev quick reference

- **`fates-edge-ai-gm-bot`** / **`fates-edge-apps`**: see each repo's own README for its install/test/run commands.
- **`fates-edge-dev`**: an Astro site — `npm install && npm run dev`.
