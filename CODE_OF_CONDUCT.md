# Code of Conduct

Fate's Edge is a welcoming space for hackers, storytellers, and curious devs of all backgrounds and experience levels.

- Be respectful. Disagree about architecture and design all you want — never about people.
- No harassment, no gatekeeping ("that's a beginner question" is not a helpful reply — everyone started somewhere).
- Assume good faith. Most confusion is a docs gap, not a bad actor.
- The maintainer (Nick) is the point of escalation for anything that violates this.

Modeled loosely on the [Contributor Covenant](https://www.contributor-covenant.org/).
